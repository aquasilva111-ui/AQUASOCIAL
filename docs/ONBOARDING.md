# Onboarding — o que é diferente no AQUA

Texto curto para explicar para quem chega no app.

## Mensagem principal

> AQUA não é só um feed.  
> É um lugar para criar junto: documentos, música, vídeo, design e mais — e publicar no mesmo perfil.

## Pontos que vale mostrar no primeiro uso

1. **Ferramentas criativas de primeira classe**  
   O Hub e o Docs não são “extras”. São parte do app.

2. **Identidade visual própria**  
   Cores Nazar (azul forte + iris), tipografia limpa, interface em português.

3. **Criar junto**  
   Colaboração em tempo real (Yjs) no Docs e no Hub.

4. **Seus dados**  
   Baseado no AT Protocol. Com PDS próprio, os dados ficam no seu servidor.

## Onde colocar no app

- Tela de boas-vindas após o primeiro login.
- Ou um card no topo do feed nas primeiras sessões.
- Ou uma página “O que é o AQUA” no menu.

## Texto sugerido (curto)

**Bem-vindo ao AQUA**

- Postar no feed

Tudo com a cara do AQUA.
